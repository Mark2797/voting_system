make - overrall compilation
make run - running the voting_system software
make test - running all tests

./voting_system - running the voting_system software with shuffling
./voting_system shuffle-off - running the voting_system software without shuffling

Procedure for running the voting_system software (you can also follow the instruction printed on the terminal):
1. Enter the correct csv file name.
2. Choose whether to enter more files or not. If so, repeat step 1 and 2 until you enter all the file names.
3. If you are running Plurality Vote (PV) and Municipal Vote (MV), the summary of the results would be printed on the terminal.
4. If you are running Single Transferable Vote (STV), the summary of the results would be printed on the terminal, and you would be asked to enter the file name you want for the output audit file.
